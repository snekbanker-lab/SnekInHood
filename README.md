## 🌐 The Site

This repo hosts the landing page — a single static HTML file, zero dependencies.

**Live:** `https://snekbanker-lab.github.io/SnekInHood/` *(once GitHub Pages is enabled: Settings → Pages → Deploy from branch → `master` / root)*

To run locally, just open the file — no build step:

```bash
# from the repo root
xdg-open snekindahood.html   # or open index.html / snekindahood.html in your browser
```

